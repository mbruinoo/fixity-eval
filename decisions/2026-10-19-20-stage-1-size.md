# 20. Stage 1: size and cost settings

- **Date:** 2026-10-19
- **Status:** approved by the repo author in chat, 2026-10-19. The run itself
  still needs the frozen pre-registration and the author's go.

## Context

The 2026-10-19 smoke test showed sessions that type out their files cost
about $0.32–0.36 each at full price, against $0.10 in spike-32, so roughly
$0.05–0.18 each in batch mode. The cost guard reserves each pending call at
its most expensive; with many sessions advancing together in batch mode, a
large reply limit makes that reserve large.

## Decision

- 20 sessions of each of stage 1's three requests (record 17): 60 in all, on
  the held-out file f.
- Cost guard $11.
- Each reply capped at 16,000 tokens (was 32,000; a 100-row sheet needs about
  6,000), and sessions run in three rounds of about 20, each round mixing all
  three requests, so the guard's reserve stays small.

## Consequences

- Expected cost about $3–11. Workspace limit $72; study spend before the run
  $56.70.
- Power (from simulation on spike-32's sessions, file e, earlier fix wording):
  for the error rate, about 99% if file f behaves like file e; for a real
  checksum of the upload, about 98% if the fix line works as often as in
  spike-32 (65%), much less if it works only as often as on the 300-row file
  (25%). The hint comparisons have no earlier data to estimate from.
