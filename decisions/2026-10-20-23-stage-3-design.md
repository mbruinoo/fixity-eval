# 23. Stage 3: Haiku 4.5, 10 sessions, exploratory

- **Date:** 2026-10-20
- **Status:** approved by the repo author in chat, 2026-10-20 (model and
  size). The run itself needs the author's go on the full proposal.

## Context

Record 06 planned stage 3 for Haiku 4.5 and possibly newer models, to see how
discoverable per-row fingerprints are; record 18 set its request. Stage 1
found that showing the possibility (the hint) led sessions that ran code to
make real per-row checksums, and most other sessions to invent them.

## Decision

- Model: Claude Haiku 4.5 only. No other model is tested, so SPEC.md §2
  needs no change.
- 10 sessions of record 18's request, on the held-out file f, in the same
  setting as stage 1 (so the two can be compared). Exploratory and
  descriptive: no hypotheses are tested.
- For each session the scripts record which way it makes rows traceable
  (record 18): the object number as the link; the original values kept in
  added columns; the original file kept with a checksum of it; per-row
  fingerprints (real or invented); none. The research coordinator reads every
  reply and records its own account and any statement about what checksums
  can or can't do, quoted exactly where the session agreed to be quoted.

## Consequences

- Results are reported as exploratory, alongside stage 1's base request
  (the same setting with no traceability request).
