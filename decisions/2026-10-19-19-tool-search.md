# 19. The emulation's tool search stays as it is

- **Date:** 2026-10-19
- **Status:** approved by the repo author in chat, 2026-10-19.

## Context

In the claude.ai emulation (record 07), the code tool is hidden until a
session finds it with a keyword search, and it's found by words like
"script", "python", "run" or "execute", not "checksum" or "hash". In spike-32
(fix line, earlier wording), the 13 of 20 sessions that ran code all made a
second search, for running scripts; the 7 that didn't searched only for a
checksum tool. Both sessions of the 2026-10-19 smoke test searched once, for
a checksum tool, and typed everything. So the search largely decides whether
code runs. How real claude.ai's tool search behaves is not known.

## Decision

Keep the search as it is, so stage 1 stays comparable with the exploratory
evidence.

## Consequences

- Reported as a limitation of the emulation, in plain language, in every
  stage that uses it.
- The scripts record each session's searches and whether the code tool was
  found, so the effect can be shown alongside the results.
- The optional real claude.ai sessions (before 2026-10-29) are the check on
  whether real claude.ai behaves the same way.
