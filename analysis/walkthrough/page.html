Read more

  • We asked Claude Haiku 4.5 to standardize a spreadsheet of 100 museum records from The Met’s Open Access data: once as is, and once with a line asking it to preserve fixity, use scripts, and checksum the sources and the results.
  • Error rate is the share of a sheet that was lost, changed or invented. Minor changes, such as a stripped accent, count for a quarter; formatting counts for nothing; links aren’t graded.
  • In the test setting, — of — sessions with the line computed a real checksum of the file. In claude.ai, none ran code, so every checksum was made up, and those sheets still had fewer errors.
  • Asking for fixity didn’t stop every invention: one claude.ai sheet with the line still filled two blank dates with “19th century”.
  • The test setting was built to make errors likely: 24 tools, a code tool that had to be searched for, and guidance that discouraged reading the file from disk. The claude.ai sessions were run by hand, five per request, in Incognito chats.
  • One model, one 100-row file and few claude.ai sessions: read these as strong hints, not final measurements.
  • If data integrity matters: ask for a script and checksums, keep the script with the result, and recompute the checksums yourself, for example with sha256sum.
