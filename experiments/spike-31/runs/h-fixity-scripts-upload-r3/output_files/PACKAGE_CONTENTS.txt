    3. In import dialog, ensure "Tab" is selected as separator
    4. Click OK
    
  In Google Sheets:
    1. File → Open
    2. Paste URL or upload file
    3. No additional configuration needed
    
  In LibreOffice Calc:
    1. File → Open
    2. Select file
    3. Choose "Tab" as separator in dialog
    4. Click OK
    
  In Python:
    import csv
    with open('met_inventory_standardized.tsv', 'r', encoding='utf-8') as f:
        reader = csv.DictReader(f, delimiter='\t')
        for row in reader:
            print(row)

  The file contains 4 columns:
  1. Object Date - When the object was created/acquired
  2. Title - Name or description of the object
  3. Object Number - Museum catalog number

  Records are sorted chronologically from BCE to 2000s
  All 101 entries from original file are present

TROUBLESHOOTING
================================================================================

PROBLEM: File won't open in Excel
  SOLUTION:
  - Try LibreOffice Calc or Google Sheets instead
  - Ensure you select "Tab" as delimiter when importing
  - Check that file hasn't been corrupted
  - Verify UTF-8 encoding in file properties

PROBLEM: Characters display as boxes or corruption
  SOLUTION:
  - Change application encoding to UTF-8
  - Use a text editor that supports UTF-8 (VS Code, Sublime, Notepad++)
  - Verify file hasn't been converted to different encoding
  - Recalculate checksums - file may be corrupted

PROBLEM: Checksum verification fails
  SOLUTION:
  - Ensure file hasn't been modified since download
  - Check you're using SHA-256 (not MD5 or other)
  - Compare checksums character-by-character carefully
  - Re-download file from original source
  - Try online checksum calculator to verify

PROBLEM: Can't run verification scripts
  SOLUTION (Linux/macOS):
  - Check Python 3 is installed: python3 --version
  - Make script executable: chmod +x verify_integrity.sh
  - Try manual verification: sha256sum met_inventory_standardized.tsv
  
  SOLUTION (Windows):
  - Run PowerShell as Administrator
  - Check execution policy: Get-ExecutionPolicy
  - Allow script execution: Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
  - Try manual verification: Get-FileHash -Path "met_inventory_standardized.tsv" -Algorithm SHA256

PROBLEM: Sorting or column order doesn't match
  SOLUTION:
  - File is correct - sorting is by date, then object number
  - Sorting may appear different based on application settings
  - Verify by checking first row (should be "4th century BCE")
  - Check last rows (should be undated entries)
