    Linux/macOS: sha256sum met_inventory_standardized.tsv

  └─ Open CHECKSUMS.txt and verify your checksums match
  └─ If checksums match: File is intact ✓
  └─ If checksums don't match: File may be corrupted ✗

  └─ Verify header: "Object Date", "Title", "Object Number", "Link Resource"
  └─ Check first record starts with "4th century BCE"
