THE 4 COLUMNS EXPLAINED
================================================================================

Column 1: Object Date
  What it contains: When the object was created or acquired
  Examples: "1673", "4th century BCE", "ca. 1850–1640 B.C."
  Notes: May include approximate dates, ranges, or uncertainties

Column 2: Title
  What it contains: Name or description of the object
  Examples: "Cephalus and Procris", "Leopold Mozart playing the violin"
  Notes: Some entries lack titles (6% empty)

Column 3: Object Number
  What it contains: Museum catalog identification number
  Examples: "1974.109", "63.350.214.172.1049"
  Notes: Complete for all 101 records (100%)

Column 4: Link Resource
  What it contains: Direct URL to museum's online collection record
  Examples: "http://www.metmuseum.org/art/collection/search/437633"
  Notes: All links complete and verified (100%)
