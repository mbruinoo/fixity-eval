❓ COMMON QUESTIONS

Q: Is all the data from the original file?
A: Yes! 100% of the data is preserved. The standardization only fixed
   formatting issues, not data. See STANDARDIZATION_REPORT.md for details.

Q: How do I know the file is real?
A: The SHA256 checksum provides cryptographic proof the file is exactly
   as delivered and hasn't been corrupted. Verify it!

Q: What if the checksum doesn't match?
A: The file may have been corrupted during transfer or modified after
   download. Re-download and try again. See VERIFY_INTEGRITY.md for help.

Q: Why are some titles [Untitled]?
A: 15 objects in the original data had no title. [Untitled] is a standard
   archival convention for such objects.

Q: Why are some dates [Unknown]?
A: 6 objects had no date information in the original data. [Unknown] marks
   these explicitly rather than using empty cells.

Q: Can I edit this file?
A: Yes, but create a new version (met_inventory_v1.1_date.tsv) and
   recalculate the checksum for your modified version.

Q: How do I cite this data?
A: See README.md for citation examples and original source information.
