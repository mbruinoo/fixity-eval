TROUBLESHOOTING
===============

ISSUE: File won't open in Excel
FIX: Try met_inventory_standardized.csv instead
    Or: File → Open → choose "All Files" → select TSV

ISSUE: Special characters show as ????
FIX: In import dialog, select UTF-8 encoding
    Or: Try opening CSV version instead

ISSUE: Data appears in wrong columns
FIX: Select correct delimiter in import wizard
    - TSV: Tab
    - CSV: Comma
    Leave quotes as: Default

ISSUE: Dates look strange
FIX: This is normal - dates have many formats
    Excel shows them as text by default (correct)
    See: met_inventory_data_dictionary.txt for format info

ISSUE: Title column is cut off
FIX: Double-click column border to auto-fit width
    Or: Manual adjust (some titles are 300+ chars)

ISSUE: URLs not clickable
FIX: Select column → Format as hyperlink
    Or: Copy URL and paste in browser
