CHANGES MADE:

1. REMOVED HTML ENTITIES

     * "Carlotta Cortudino" → Carlotta Cortudino

   - Titles in square brackets converted to standard format
   - Examples:
     * [Carlotta Cortudino] → Carlotta Cortudino
     * [First Methodist Church, Temple Street, Beacon Hill, Boston, Massachusetts] →
