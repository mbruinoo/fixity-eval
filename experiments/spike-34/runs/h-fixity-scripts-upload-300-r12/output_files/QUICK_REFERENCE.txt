================================================================================
TROUBLESHOOTING
================================================================================

Problem: File won't open / shows garbled text
Solution: Ensure UTF-8 encoding is selected in your application

Problem: Extra columns appearing / misaligned data
Solution: Confirm Tab is selected as delimiter (not comma or space)

Problem: Empty Title fields appear as errors
Solution: This is normal - 46 records have empty titles in original data

Problem: Checksum doesn't match
Solution: File may have been modified, check using:
          ls -l met_inventory_standardized.tsv
          stat met_inventory_standardized.tsv

Problem: Can't run Python script
Solution: Make sure Python 3 is installed:
          python3 --version
          Then run: python3 verify_fixity.py

Problem: Lines appear to have extra characters at end
Solution: File is using LF line endings (correct). Your editor may be
          showing them differently. This is not a problem.
