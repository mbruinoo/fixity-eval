FIXITY VERIFICATION EXPLAINED

What is fixity?
  Assurance that data has not changed, been corrupted, or been modified.

How does it work?
  Cryptographic checksums create unique fingerprints of your file.
  If any bit changes, the fingerprint changes.

Why should you care?
  Ensures your data integrity, especially for archival purposes.

How to verify:
  1. Run: python3 04_checksum_result.py
  2. Script compares current file against stored checksums
  3. Output tells you if file is authentic

Expected results:
  ✓ Source and result have different checksums (standardization made changes)
  ✓ Data row counts match (461 records preserved)
  ✓ URLs all present and identical
  ✓ File is authentic and unchanged since standardization
