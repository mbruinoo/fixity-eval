FIXITY VERIFICATION EXPLAINED
================================================================================

WHAT ARE CHECKSUMS?
  Cryptographic fingerprints that uniquely identify file contents.
  If even one byte changes, the checksum changes.

HOW TO USE THEM:
  1. Before using the file: Run 04_checksum_result.py
  2. Script compares current file against stored checksums
  3. If checksums match → File is authentic and unchanged
  4. If checksums don't match → File may be corrupted

EXPECTED RESULTS:
  • Source MD5 ≠ Result MD5 (EXPECTED - file was standardized)
  • Source row count = Result row count (EXPECTED - data preserved)
  • All URLs identical (EXPECTED - not modified)
  • File size different (EXPECTED - headers/formatting changed)
