TROUBLESHOOTING
===============

"File won't import into my tool"
  └─ Solution: Ensure UTF-8 encoding is selected
  └─ Verify: Tab delimiter (not comma)
  └─ Check: File is named *.tsv (not *.txt)

"My tool says encoding error"
  └─ Solution: Remove BOM if using Windows
  └─ Try: Re-encode file to UTF-8 without BOM
  └─ Check: All multilingual content in records 0089-0100

"Verification script won't run"
  └─ Solution: Ensure Python 3.6 or higher
  └─ Check: Both TSV files in same directory
  └─ Try: python3 verify_integrity.py (on Mac/Linux)

"Numbers don't match my expected checksum"
  └─ Solution: Formatting changes are intentional
  └─ Check: Record content hash, not file hash
  └─ Read: STANDARDIZATION_REPORT.md for details
