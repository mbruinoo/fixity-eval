FIXITY GUARANTEE
════════════════════════════════════════════════════════════════════════════════

What Fixity Means:
  ✓ Data hasn't changed (verified by checksums)
  ✓ Nothing was deleted
  ✓ Nothing was added secretly
  ✓ Complete audit trail maintained
  ✓ Long-term preservation confirmed

How It Works:
  • Each record has a SHA256 checksum
  • Checksums are cryptographically secure
  • If data changes, checksum changes
  • Compare checksums to verify integrity
  • Scripts provided to automate this

When to Use Checksums:
  → After downloading files
  → After transferring between systems
  → Before archiving
  → Periodically during storage
  → Before publishing/sharing
