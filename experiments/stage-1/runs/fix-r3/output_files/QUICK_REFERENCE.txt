================================================================================
DATA STRUCTURE
═════════════════════════════════════════════════════════════════════════════

Column 1: Object Date
─────────────────
Examples:
  - "19th century"
  - "ca. 1830–32"
  - "5th century BCE"
  - "1949, printed ca. 1976"
  - "August 26, 1873"
  - "n.d." (no date)
  - "1777"

Column 2: Title
──────────────
Examples:
  - "Bracelet"
  - "Bust of a gentleman in contemporary dress"
  - "Hudson Street"
  - "[Unidentified Woman]"
  - "S. Héribert, évêque de Cologne..."
  - "" (empty for some objects)

Note: Some titles include museum catalog notes and exhibit series info

Column 3: Object Number
──────────────────────
Format: Museum internal catalog identifier
Examples:
  - "91.1.396"
  - "1992.72.44"
  - "63.350.619.451.6"
  - "Burdick 223, N346.4"
  - "2009.88a–c"

Column 4: Link Resource
──────────────────────
Format: Direct URL to museum collection page
Pattern: http://www.metmuseum.org/art/collection/search/[ID]
Example: http://www.metmuseum.org/art/collection/search/51219

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

❌ "File not found"
   → Check you're in correct directory: pwd
   → List files: ls -la
   → Try with full path: /path/to/file.tsv

❌ "Encoding issues (garbled characters)"
   → File should be UTF-8 (check: file -i met_inventory_standardized.tsv)
   → In Python: ensure open(..., encoding='utf-8')
   → In Excel: check data encoding settings

❌ "Tabs look like spaces"
   → They ARE tabs (special character, not spaces)
   → Some editors show them as spaces
   → Check: hexdump -C file.tsv | head
   → Should see 09 (hex) = tab character

❌ "Script permission denied"
   → Make executable: chmod +x script.sh
   → Then run: ./script.sh

❌ "Python: No module named pandas"
   → Install: pip install pandas
   → Check version: python3 --version (needs 3.6+)

✓ Report issue with file integrity?
   → Run: bash verify_integrity.sh
   → Check VERIFICATION.txt for expected checksums
   → Re-download file from source
