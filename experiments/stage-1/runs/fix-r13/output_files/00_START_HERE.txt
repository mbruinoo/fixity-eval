                        COMMON QUESTIONS
================================================================================

Q: Can I use both files interchangeably?
A: Yes! Both files are identical (checksums match exactly).
   Use whichever you prefer. The "standardized" version ensures
   consistent formatting for long-term preservation.

Q: What if I modify the file?
A: The checksums will change. This is expected.
   Document any modifications and generate new checksums.
   See PRESERVATION_CHECKLIST.md for procedures.

Q: How do I know the file hasn't been corrupted?
A: Run: sha256sum -c met_inventory_standardized.tsv.sha256
   If you see "OK", the file is verified as uncorrupted.

Q: Can I open this in Excel?
A: Yes! Excel will open TSV files. 
   Ensure UTF-8 encoding is selected.
   Alternatively, rename to .csv extension.

Q: What about the three empty Title fields?
A: This is original data (rows 2-4 had no titles in the source).
   They were preserved intentionally, not standardization errors.

Q: Why are there different date formats?
A: The museum uses varied formats intentionally for historical accuracy.
   The standardization process preserved these exactly.

Q: Is my data really safe?
A: Yes! Multiple verification methods confirm it:
   - Cryptographic SHA-256 checksums
   - Legacy MD5 checksums
   - Structural validation
   - Encoding verification
   This is professional data preservation practice.
