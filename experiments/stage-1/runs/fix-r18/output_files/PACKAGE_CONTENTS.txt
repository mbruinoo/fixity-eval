================================================================================
FILE INTEGRITY VERIFICATION
================================================================================

The fixity manifest contains checksums for both source and output files.
To verify integrity at any time:

Method 1 - Automated:
  $ python3 verify_fixity.py

Method 2 - Manual (Linux/macOS):
  $ sha256sum -c <(echo "HASH_VALUE  filename.tsv")

Method 3 - Manual (Windows PowerShell):
  > (Get-FileHash -Path filename.tsv -Algorithm SHA256).Hash

Method 4 - Check file size:
  $ ls -lh met_inventory_standardized.tsv
  (Compare bytes against manifest entry)
