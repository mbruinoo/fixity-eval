CHECKSUM ALGORITHM DETAILS
================================================================================

Algorithm: SHA-256 (Secure Hash Algorithm)

    Input: Tab-separated record data (any length)
        │
        ├─ Divide into 512-bit blocks
        ├─ Apply 64 rounds of cryptographic operations
        ├─ Combine with previous values
        └─ Iterate through all blocks
        │
        ↓
    Output: 256-bit (32-byte) hash
        │
        ├─ Represented as 64 hexadecimal characters
        ├─ Unique to input data
        ├─ Sensitive to any change (single bit change → different hash)
        └─ Collision probability: negligible

MULTI-SOURCE VERIFICATION
================================================================================

To verify data integrity using multiple sources:

Source 1: Automated script
    python3 standardize_met_inventory.py
    └─ Output: "✓ All 100 checksums verified"

Source 2: Manual calculation
    echo -n "19th century\t\t91.1.396\t..." | sha256sum
    └─ Compare with met_inventory_checksums.tsv

Source 3: Independent script
    python3 << 'EOF'
    import hashlib, csv
    with open('met_inventory_standardized.tsv') as f:
        for row in csv.DictReader(f, delimiter='\t'):
            data = f"{row['date']}\t{row['title']}\t{row['object_number']}\t{row['url']}"
            h = hashlib.sha256(data.encode()).hexdigest()
            if h != row['std_checksum']:
                print(f"MISMATCH: Row {row['row_number']}")
    EOF
    └─ Independent verification

If all three match → Data integrity extremely high
