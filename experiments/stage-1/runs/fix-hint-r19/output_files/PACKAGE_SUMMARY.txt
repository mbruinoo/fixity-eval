CHECKSUM MECHANISM
================================================================================

Purpose: Preserve data fixity and enable integrity verification

Source Checksum Calculation:
  SHA-256(Original Date \t Original Title \t Original Object # \t Original URL)
  └─ Links standardized record back to original source

Standardized Checksum Calculation:
  SHA-256(Standardized Date \t Standardized Title \t Standardized Object # \t URL)
  └─ Enables detection of any data corruption or modification

Verification Method:
  1. Extract record data from standardized TSV
  2. Reconstruct tab-separated format
  3. Calculate SHA-256 hash
  4. Compare with recorded std_checksum
  5. Match = data integrity verified
