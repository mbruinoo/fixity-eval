           Check encoding is UTF-8

ABOUT THE CHECKSUMS
================================================================================

Why checksums?
  → Detect any data corruption or modification
  → Preserve data integrity over time
  → Enable verification by anyone

What is SHA-256?
  → Cryptographic hash algorithm
  → Produces unique 64-character string for any data
  → Industry standard (used by banks, governments, archives)

Two checksums per record:
  1. source_checksum: Hash of original data (for comparison)
  2. std_checksum: Hash of standardized data (for verification)

How to verify:
  → Automated: Run Python script (1 minute)
  → Manual: Calculate hash and compare (10 minutes per record)
  → Spot-check: Sample 5 random records (2 minutes)

Complete verification: All 100 checksums match = Data integrity confirmed
