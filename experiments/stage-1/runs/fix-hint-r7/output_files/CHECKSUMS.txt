ABOUT THIS PROCESS
==================

Fixed Metadata Approach:
  - Checksums computed for full files
  - Checksums computed for individual rows
  - No cryptographic signing applied
  - All hashes are reproducible and verifiable

Why Multiple Checksums?
  - Full file checksum detects any overall change
  - Row checksums detect specific modifications
  - Combined approach enables precise change detection
  - Useful for audit trails and compliance

When to Re-Standardize?

  - If standardization rules need updating
  - For periodic integrity verification
  - For archival versioning
