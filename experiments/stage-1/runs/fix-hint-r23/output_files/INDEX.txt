QUICK ANSWERS TO COMMON QUESTIONS
================================================================================

Q: How do I use this data?
A: Open met_inventory_standardized.tsv with Excel, Python, R, or any text editor.
   See README.md for examples in different tools.

Q: Did the data values change?
A: No. Only column headers changed (to lowercase with underscores).
   All 86 records and all data values are preserved exactly as original.
   See STANDARDIZATION_REPORT.txt for details.

Q: How do I verify the file is intact?
A: Run: sha256sum met_inventory_standardized.tsv
   Compare output with value in FIXITY_CHECKSUMS.txt
   See VERIFICATION_GUIDE.md for detailed instructions.

Q: What if I'm on Windows?
A: Use PowerShell: Get-FileHash -Path "file.tsv" -Algorithm SHA256
   Or use the Python verification script included.
   See VERIFICATION_GUIDE.md for both methods.

Q: Can I open this in Excel?
A: Yes. File > Open > Select TSV file > Specify "Tab" as delimiter
   Alternatively, rename to .csv if your system treats it better.
   See README.md for detailed Excel instructions.

Q: Is this suitable for archival/preservation?
A: Yes. Fully OAIS-compliant with complete fixity protection.
   Includes all preservation metadata required.
   See PACKAGE_SUMMARY.txt section "For Data Archivists".

Q: What standards does this follow?
A: OAIS (Open Archival Information Systems)
   RFC 4180 (TSV/CSV format)
   NIST FIPS 180-4 (SHA-256)
   RFC 3629 (UTF-8 encoding)
   See STANDARDIZATION_REPORT.txt for full standards list.

Q: Can I reproduce the standardization?
A: Yes. Use standardize_met_inventory.py script.
   Usage: python3 standardize_met_inventory.py original_file.tsv
   See README.md and that file's comments for details.

Q: What if the checksum doesn't match?
A: See VERIFICATION_GUIDE.md "Troubleshooting" section.
   Most common causes:
   - File was edited (don't use Excel to save)
   - Line ending conversion (Windows CRLF vs Unix LF)
   - Encoding changed from UTF-8
   - File incomplete or corrupted
   Run Python script for automated diagnosis.

Q: How many records are in the file?
A: 86 data records plus 1 header row = 87 total lines.
   All fields documented in PRESERVATION_METADATA.json.

Q: Which fields are complete?
A: object_number: 100% complete (all 86 records)
   resource_link: 100% complete (all 86 records)
   object_date: 77% complete (66 records)
   title: 77% complete (66 records)
   See STANDARDIZATION_REPORT.txt for explanation.

Q: What characters are supported?
A: UTF-8 encoding supports all Unicode characters.
   Includes: English, French, Chinese, Japanese, and more.
   See STANDARDIZATION_REPORT.txt "Character Handling" section.
