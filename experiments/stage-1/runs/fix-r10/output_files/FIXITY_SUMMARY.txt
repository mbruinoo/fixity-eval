COLUMN REFERENCE
================================================================================

Column 1: Object Date
  Description: Date or period when artwork was created
  Format: Various (centuries, specific years, date ranges)
  Examples: "19th century", "ca. 1830–32", "August 26, 1873"

Column 2: Title
  Description: Name or description of the artwork
  Format: Free text
  Note: Some entries are empty (intentional)
  Examples: "Bust of a man", "L'Accord Parfait (Perfect Harmony)"

Column 3: Object Number
  Description: Museum catalog/accession number
  Format: Alphanumeric with dots and hyphens
  Examples: "91.1.396", "C.I.64.69.2", "JP1328"

Column 4: Link Resource
  Description: URL to the object in the Met's online collection
  Format: HTTP URL
  Pattern: http://www.metmuseum.org/art/collection/search/[ID]
