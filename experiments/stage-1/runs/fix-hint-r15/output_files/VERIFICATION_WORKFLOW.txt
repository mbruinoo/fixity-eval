================================================================================
MET INVENTORY TSV STANDARDIZATION
VERIFICATION WORKFLOW & CHECKSUM GUIDE
================================================================================

This guide provides step-by-step procedures to verify the integrity of your
standardized file using checksums and data validation techniques.

================================================================================
PART 1: QUICK VERIFICATION (2 minutes)
================================================================================

Task 1.1: Verify File Integrity
--------------------------------
Command:
    sha256sum met_inventory_standardized.tsv

Expected Output:
    [64-character hexadecimal string]  met_inventory_standardized.tsv

This verifies the file has not been corrupted or modified.

---

Task 1.2: Count Rows
-------------------
Command:
    wc -l met_inventory_standardized.tsv

Expected Output:
    96 met_inventory_standardized.tsv
    (95 data rows + 1 header row)

This confirms all records are present.

---

Task 1.3: Verify Field Names
----------------------------
Command:
    head -1 met_inventory_standardized.tsv

Expected Output:
    Object_Date	Title	Object_Number	Link_Resource

This confirms field names were standardized correctly.

================================================================================
PART 2: COMPREHENSIVE VERIFICATION (10 minutes)
================================================================================

Task 2.1: Check File Format
---------------------------
Command:
    file met_inventory_standardized.tsv

Expected Output:
    ASCII text, with very long lines, with no line terminators

This confirms the file is plain text in the correct format.

---

Task 2.2: Verify Encoding
------------------------
Command:
    file -i met_inventory_standardized.tsv

Expected Output:
    text/plain; charset=utf-8

This confirms UTF-8 encoding is maintained.

---

Task 2.3: Spot-Check Row Count
------------------------------
Command:
    tail -1 met_inventory_standardized.tsv

Expected Output:
    ca. late 1150s	金 傳楊邦基 聘金圖 巻|A Diplomatic Mission to the Jin	1982.1.1	http://www.metmuseum.org/art/collection/search/39959

This should be the last record in the file. The Chinese characters should
display correctly, confirming UTF-8 integrity.

---

Task 2.4: Verify Tab Delimiters
-------------------------------
Command:
    head -2 met_inventory_standardized.tsv | od -c | grep "\\t"

Expected Output:
    Shows multiple tab characters (\\t or \t depending on display)

This confirms tabs are used as delimiters (not spaces).

---

Task 2.5: Check for Problematic Characters
-------------------------------------------
Command:
    grep -P "[\x00-\x08\x0B-\x0C\x0E-\x1F]" met_inventory_standardized.tsv

Expected Output:
    (No output - meaning no control characters found)

This confirms file is free of corruption.

PART 4: ADVANCED VERIFICATION (10-15 minutes)
================================================================================

Task 4.1: Hash All Rows Individually
-----------------------------------
Command:
    tail -n +2 met_inventory_standardized.tsv | while IFS= read -r line; do
      echo -n "$line" | sha256sum
    done | head -20

This produces a SHA256 hash for each row. These can be compared against
the checksums in met_inventory_checksums.json for granular verification.

---

Task 4.2: Verify Data Type Consistency
-------------------------------------
Command:
    cut -f3 met_inventory_standardized.tsv | tail -n +2 | head -20

Expected Output:
    91.1.396
    1972.45.1
    44.17.1
    [etc. - all Object_Number values]

Verification Points:
    ✓ Consistent format for object numbers
    ✓ No unexpected variations
    ✓ Numbers and dots/commas intact

---

Task 4.3: Verify URL Integrity
-----------------------------
Command:
    cut -f4 met_inventory_standardized.tsv | tail -n +2 | head -10

Expected Output:
    http://www.metmuseum.org/art/collection/search/51219
    http://www.metmuseum.org/art/collection/search/65665
    [etc. - all URLs should start with http://]

Verification Points:
    ✓ All URLs present
    ✓ URLs not modified
    ✓ Proper format maintained

---

Task 4.4: Find Rows with Special Characters
-------------------------------------------
Command:
    grep -n '[éèêëôäâàöüñ]' met_inventory_standardized.tsv

Expected Output:
    [Line numbers with accented characters]

This identifies rows with French or other European accents for spot-checking.

---

Task 4.5: Find Multi-Script Rows
-------------------------------
Command:
    grep -P '[^\x00-\x7F]' met_inventory_standardized.tsv | wc -l

Expected Output:
    8 (approximately - varies based on how grep handles UTF-8)

This counts rows containing non-ASCII characters (Chinese, Japanese, accents).

TROUBLESHOOTING
================================================================================

Problem: "File encoding shows as 'unknown'"
Solution: 
    file -i met_inventory_standardized.tsv
    iconv -f UTF-8 -t UTF-8 -c met_inventory_standardized.tsv > fixed.tsv

Problem: "Checksums don't match between systems"
Solution: Check for different line endings (Unix vs Windows)
    dos2unix met_inventory_standardized.tsv
    sha256sum met_inventory_standardized.tsv

Problem: "Special characters display as ?"
Solution: Ensure your terminal supports UTF-8
    export LANG=en_US.UTF-8
    cat met_inventory_standardized.tsv | head

Problem: "Tab delimiters appear as spaces"
Solution: Use od or hexdump to verify
    od -c met_inventory_standardized.tsv | grep "\\t" | head
