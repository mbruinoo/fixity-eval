INTEGRITY & FIXITY SYSTEM
================================================================================

CHECKSUM ALGORITHM: SHA256 (NIST-approved)

Coverage:
  • Every data row has a checksum
  • Checksums cover columns 1-4
  • Format: 64 hexadecimal characters
  • Generation: Automated, verified

What Checksums Detect:
  ✓ Bit-rot (data corruption)
  ✓ Unauthorized modifications
  ✓ Character encoding issues
  ✓ Whitespace/punctuation changes
  ✓ Truncation or padding attacks

What Checksums Don't Detect:
  ✗ Wholesale file replacement (use file-level checksums)
  ✗ Row deletion (use row-count verification)
  ✗ Consistent changes applied to all rows

Verification Options:
  1. Simple (Linux/Mac): echo -n "data" | sha256sum
  2. Python (Recommended): python verify_checksums.py file.tsv
  3. Manual (Reference): Compare with CHECKSUMS_REFERENCE.txt
