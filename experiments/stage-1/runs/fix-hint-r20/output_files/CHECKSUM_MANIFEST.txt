================================================================================
CHECKSUM VERIFICATION SYSTEM
================================================================================

ALGORITHM: SHA256 (NIST-approved cryptographic hash function)
SCOPE: Per-row checksums + optional whole-file validation

HOW TO USE CHECKSUMS FOR FIXITY:

1. VERIFY SINGLE RECORD INTEGRITY:
   - Extract the checksum value from column 5 for any row
   - Recalculate SHA256 of that row's data (columns 1-4, tab-delimited)
   - Compare: if checksums match, row is unchanged
   - If mismatch: row has been corrupted or tampered with

2. DETECT UNAUTHORIZED MODIFICATIONS:
   - Missing values vs. [Unknown] placeholder
   - Quote and punctuation changes
   - Spelling alterations
   - Character encoding issues

3. IDENTIFY PROBLEMATIC ROWS:
   - Focus on entries with missing Object Date or Title
   - These may require curator review
   - Checksum provides baseline for future comparison
