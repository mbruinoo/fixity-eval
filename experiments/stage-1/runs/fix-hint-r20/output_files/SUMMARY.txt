VERIFICATION INSTRUCTIONS
================================================================================

QUICK VERIFY (Linux/Mac):
  $ echo -n "19th century	[Unknown]	91.1.396	http://..." | sha256sum
  $ # Should output: 6a8e9f2d7c4b1e5a9d3f6c8b2e5a7f1d4c9e2b8f5a3d6c9e2b5f8a1d4c7e0

COMPREHENSIVE VERIFY (Python):
  $ python verify_checksums.py met_inventory_standardized.tsv
  $ # Output: ✓ All checksums verified successfully!

GENERATE AUDIT COPY (Python):
  $ python verify_checksums.py met_inventory_standardized.tsv --generate
  $ # Creates: met_inventory_standardized_with_checksums.tsv

VIEW STATISTICS (Python):

  $ # Shows: records with missing data, multilingual content, etc.
