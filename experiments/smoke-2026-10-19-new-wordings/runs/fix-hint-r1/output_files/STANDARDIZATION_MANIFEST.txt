VERIFICATION PROCEDURES
================================================================================

Method 1: File-Level Checksum Verification
  1. Open command line/terminal
  2. Navigate to directory containing standardized TSV
  3. Run: sha256sum met_inventory_standardized.tsv
  4. Compare output to checksum in FIXITY_REPORT.md
  5. If checksums match: File integrity confirmed
  6. If checksums differ: File may be corrupted

Method 2: Row-Level Verification (Python Example)
  import hashlib
  
  # Read standardized file
  with open('met_inventory_standardized.tsv', 'r', encoding='utf-8') as f:
      rows = f.readlines()
  
  # Verify each row
  for idx, row in enumerate(rows):
      # Remove newline for consistent checksum
      row_content = row.rstrip('\n')
      row_hash = hashlib.sha256(row_content.encode('utf-8')).hexdigest()
      print(f"Row {idx}: {row_hash}")
  
  # Compare row hashes to stored values in fixity report

Method 3: Spot-Check Data Validation
  1. Open standardized file in text editor
  2. Verify column headers in first row
  3. Sample several data rows for proper formatting
  4. Check that all 4 columns present
  5. Verify special characters preserved (look for international text)
  6. Check URLs are complete and properly formatted

RECOVERY PROCEDURES
================================================================================

If File Corruption Detected:
  1. Do NOT attempt to repair - may worsen corruption
  2. Use backup copy of met_inventory_standardized.tsv
  3. Re-run standardization script if needed: python3 standardize_met_inventory.py
  4. Verify against FIXITY_REPORT.md checksums
  5. If checksum mismatch persists, source data may be corrupted

If Individual Row Corruption Detected:
  1. Compare row data to Museum's web interface
  2. Cross-reference with Object Number in column 3
  3. Retrieve correct data from museum website
  4. Use museum URL in column 4 to access official record
  5. Manually repair row or request re-standardization
