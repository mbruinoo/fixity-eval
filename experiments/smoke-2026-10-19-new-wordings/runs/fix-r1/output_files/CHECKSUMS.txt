SHA-256 Hash Properties:
- Length: Always 64 hexadecimal characters
- Deterministic: Same input → Same hash (always)
- Sensitive: One bit change → Completely different hash
- One-way: Cannot reverse hash to get original file
- Collision: Virtually impossible for two files to match

TROUBLESHOOTING CHECKSUM VERIFICATION

Problem: "sha256sum: command not found"
Solution: 
  - Linux/macOS: Should be pre-installed. Try: which sha256sum
  - Windows: Use: certutil -hashfile [file] SHA256
  - Python: Use provided Python script

Problem: "File not found"
Solution:
  - Verify file path is correct
  - Check file is in current directory
  - Use full path: /mnt/user-data/outputs/met_inventory_standardized.tsv

Problem: "Checksum doesn't match"
Solutions:
  - File may have been modified (check for unsaved edits)
  - Re-download file from source
  - Verify against fixity_report.json original value
  - Contact IT if file was accessed by others

Problem: "Different hash after file modification"
Expected: If you modify the file, hash will change
Solution: Only verify unmodified files. Original file preserved
         for comparison with standardized version.
