================================================================================
TRANSFORMATIONS APPLIED
================================================================================

1. DATE NORMALIZATION
   - "ca." → "c." (standard circa abbreviation)
   - "B.C." → "BCE"
   - "A.D." → "CE"
   - Empty/missing dates → "[Date Unknown]"
   - Date ranges standardized with en-dash (–): e.g., "1780-99" → "1780–99"
   - First letter capitalized: "late 19th century" → "Late 19th century"
   - Special values: "n.d." → "[Date Unknown]"

   Examples:
   - "ca. 1780" → "c. 1780"
   - "664–30 B.C." → "664–30 BCE"
   - "" (empty) → "[Date Unknown]"

2. TITLE STANDARDIZATION
   - Empty/missing titles → "[Untitled]"
   - Remove surrounding quotation marks
   - HTML entities decoded: "&lt;i&gt;" → plain text
   - Title case applied to all words
   - Excessive whitespace normalized
   - Special articles/prepositions kept lowercase (except first word):
     "a", "an", "the", "and", "or", "for", "to", "of", "in", "by", "from",
     "with", "as", "at"

   Examples:
   - "" (empty) → "[Untitled]"
   - "\"Altitude\"" → "Altitude"
   - "Arrowhead (&lt;i&gt;Yanone&lt;/i&gt;)" → "Arrowhead (Yanone)"
   - "amulet of ptah-sokar" → "Amulet of Ptah-Sokar"

3. OBJECT NUMBER NORMALIZATION
   - Abbreviated ranges expanded: "2002.201.111, .112" → "2002.201.111, 2002.201.112"
   - Dashes in ranges converted to en-dash (–): "1a-c" → "1a–c"
   - Preserved all original object number formats

   Examples:
   - "2002.201.111, .112" → "2002.201.111, 2002.201.112"
   - "14.40.872a-c" → "14.40.872a–c"
   - "36.100.156a, b" → "36.100.156a, b" (unchanged)

4. GENERAL CLEANUP
   - Removed leading/trailing whitespace from all fields
   - Consistent punctuation and spacing
   - Preserved link resources as-is
