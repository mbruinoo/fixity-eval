================================================================================
KEY TRANSFORMATIONS APPLIED
================================================================================

DATE NORMALIZATION:
  "ca. 1780" → "c. 1780"
  "664–30 B.C." → "664–30 BCE"
  "" (empty) → "[Date Unknown]"
  "late 19th century" → "Late 19th century"
  "1780-99" → "1780–99" (dash normalization)

TITLE STANDARDIZATION:
  "" (empty) → "[Untitled]"
  ""Altitude"" → "Altitude" (remove quotes)
  "Arrowhead (&lt;i&gt;Yanone&lt;/i&gt;)" → "Arrowhead (Yanone)" (decode HTML)
  "amulet of ptah-sokar" → "Amulet of Ptah-Sokar" (title case)

OBJECT NUMBER NORMALIZATION:
  "2002.201.111, .112" → "2002.201.111, 2002.201.112" (expand abbreviation)
  "14.40.872a-c" → "14.40.872a–c" (normalize dashes)
