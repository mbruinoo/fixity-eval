RFC 4180 - CSV Format:
  https://tools.ietf.org/html/rfc4180

TSV Best Practices:
  - Use tab (U+0009) as delimiter
  - Use LF (U+000A) for line endings
  - UTF-8 encoding
  - Consistent column count

Checksum Verification:
  - MD5: Fast, legacy support, suitable for fixity
  - SHA-1: Better collision resistance
  - SHA-256: Cryptographically secure, recommended
