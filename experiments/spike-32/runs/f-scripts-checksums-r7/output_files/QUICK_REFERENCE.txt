DATA STRUCTURE
================================================================================

Column 1: Object Date
  Type: String/Text
  Format: Various (see DATA_QUALITY_ANALYSIS.txt for detailed breakdown)
  Examples: "1673", "ca. 1850–1640 B.C.", "spring/summer 1982"
  Completeness: 100% (all rows have dates)

Column 2: Title
  Type: String/Text
  Format: Descriptive titles (may include non-ASCII characters)
  Examples: "Cherub and shell", "Landscape", "Kettle and stand"
  Completeness: 91.5% (9 empty titles preserved as original data)
  Note: Contains Chinese, Japanese, Korean text in some records

Column 3: Object Number
  Type: String (DO NOT TREAT AS INTEGER)
  Format: Highly variable catalog numbers
  Examples: "58.115", "81.1.377a, b", "Burdick 218, N224.309"
  Completeness: 100% (all rows have object numbers)
  Note: Store as text to preserve leading zeros and complex formats

Column 4: Link Resource
  Type: URL
  Format: http://www.metmuseum.org/art/collection/search/[ID]
  Completeness: 100% (all rows have links)
  Note: All links valid and point to Met Museum collection

COMMON ISSUES & SOLUTIONS
================================================================================

PROBLEM: "Wrong number of columns" error
SOLUTION: The standardized file should always have exactly 4 columns (tab-delimited)
  Check: Is your file encoded as UTF-8?
  Check: Have you added/removed any tabs accidentally?
  Fix: Re-download the standardized TSV file

PROBLEM: Special characters showing as ??? or boxes
SOLUTION: Your application isn't using UTF-8 encoding
  Excel: Open → Data → Text to Columns → Encoding UTF-8
  Terminal: export LANG=en_US.UTF-8
  Python: Open with encoding='utf-8'
  Fix: Always explicitly select UTF-8 encoding

PROBLEM: Copy/paste creates weird line breaks
SOLUTION: TSV files need special handling
  Excel: Use File → Open (not copy-paste into empty sheet)
  Google Sheets: Use "Upload" option (not copy-paste)
  Fix: Always use proper import/open functions

PROBLEM: Checksum doesn't match
SOLUTION: File has been modified or corrupted
  Check: Is the file completely downloaded?
  Check: Has it been opened and re-saved in different format?
  Check: Did line endings get converted (CRLF vs LF)?
  Fix: Re-download original or regenerate using Python script
