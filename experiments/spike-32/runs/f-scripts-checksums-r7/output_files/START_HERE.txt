ABOUT THE DATA
================================================================================

Source: The Metropolitan Museum of Art Collection
Records: 94 museum objects (paintings, sculptures, textiles, etc.)
Date Range: Ancient Egypt (1850-1640 B.C.) to 20th century (1989)
Languages: English, French, Italian, German, Spanish, Chinese, Japanese, Korean

Each Record Contains:
  1. Object Date (when it was created)
  2. Title (descriptive name or artist title)
  3. Object Number (museum catalog ID)
  4. Link Resource (direct URL to museum collection page)

Example Record:
  1673 | "Corneille Emmantelée, Monedula, Chouca" (Crows, Jackdaws)...
        | 56.644.21(15) | http://www.metmuseum.org/art/collection/search/393569

All data is accurate as of the standardization date (January 2025).

COMMON QUESTIONS
================================================================================

Q: Can I download the original Met Museum objects from these URLs?
A: Many are in the public domain! Visit the URL in each record.
   The Met Museum has open access to thousands of high-res images.
   See: https://www.metmuseum.org/about-the-met/policies-and-documents/open-access

Q: Can I use this data for commercial purposes?
A: Yes, for public domain works. Check the Met Museum's open access policy.

Q: What if I find an error in the data?
A: This is standardized Met Museum data. Report issues to the Met Museum.

Q: Can I modify or redistribute these files?
A: Yes, but include documentation and credit the Met Museum.

Q: Do I need special software to open the data?
A: No. Any text editor, spreadsheet, or database will work.

Q: Why are some titles empty?
A: Some museum objects lack recorded titles - this is original data.

Q: What does the file size reduction mean?
A: The standardized version is 0.4% smaller due to whitespace cleaning.
   No data was lost - the information is identical.

Q: Can I import this to my database?
A: Yes! See README.md section "Using the Data" for SQL examples.
