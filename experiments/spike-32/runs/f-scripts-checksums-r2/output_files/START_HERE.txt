COMMON QUESTIONS (With Quick Answers)
=====================================

Q: Is the data ready to use?
A: Yes! Run standardize_tsv.py first to verify, then use it.

Q: How do I verify the data hasn't been corrupted?
A: Run: python3 standardize_tsv.py
   It will show checksums and create an integrity report.

Q: Can I open this in Excel?
A: Yes. File → Open → UTF-8 encoding → Tab delimiter

Q: I found the data is missing some titles. Is this a problem?
A: No. This is expected for archival data (noted in integrity report).

Q: What are these "checksums"?
A: Unique fingerprints of the file. Use them to detect changes.
   See: STANDARDIZATION_DETAILS.txt → Checksum Section

Q: How often should I verify?
A: Run verification after each major operation or yearly for archives.

Q: Can I modify this data?
A: Yes, but store original separately. Re-verify after changes.

Q: What if Python/R/Excel can't load the file?
A: See README.md → Common Issues & Solutions
