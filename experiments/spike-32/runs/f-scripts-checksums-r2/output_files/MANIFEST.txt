INSTALLATION & SETUP
====================

Minimum Requirements:
  ✓ Python 3.6+ (for standardization script)
  ✓ Bash 3.2+ (for verification script, optional)
  ✓ Text editor with UTF-8 support
  ✓ ~100 MB disk space (for data + scripts + reports)

Step 1: Extract Files
  - Save all files to a working directory
  - Maintain file names exactly as listed

Step 2: Make Scripts Executable (Linux/macOS)
  $ chmod +x standardize_tsv.py
  $ chmod +x verify_integrity.sh

Step 3: Verify Setup
  $ python3 standardize_tsv.py --help
  $ ls -la *.tsv *.py *.sh

Step 4: Run First Verification
  $ python3 standardize_tsv.py met_inventory.tsv met_inventory_standardized.tsv

Step 5: Check Results
  $ cat met_inventory_standardized_integrity.txt

Step 6: Load Data
  See README.md for examples in Python, R, Excel, etc.
