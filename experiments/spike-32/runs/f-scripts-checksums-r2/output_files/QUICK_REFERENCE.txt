TROUBLESHOOTING
---------------

Q: Script won't run (Python)
A: Ensure Python 3 installed
   $ python3 --version
   $ python3 standardize_tsv.py

Q: "Module not found"
A: csv/hashlib are standard library
   Try: python3 -c "import csv; print('OK')"

Q: Script won't run (Bash)
A: Make executable first
   $ chmod +x verify_integrity.sh
   $ ./verify_integrity.sh

Q: Different checksums?
A: Normal! Standardization modifies formatting.
   Content data unchanged, only format normalized.

Q: File won't open in Excel
A: Use UTF-8 import mode
   - Open Excel
   - Data → Get External Data → From Text
   - Choose UTF-8 encoding
   - Tab delimiter

Q: Encoding issues?
A: Verify file is UTF-8
   $ file -i met_inventory_standardized.tsv
   $ iconv -f UTF-8 file.tsv -t UTF-8 (validate)
