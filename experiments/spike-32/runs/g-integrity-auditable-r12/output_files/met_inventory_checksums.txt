To verify a specific record hasn't been corrupted:

1. Identify the row number you want to verify
2. Find the corresponding checksum below
3. Reconstruct the record: ObjectDate|Title|ObjectNumber|URL
4. Compute: sha256sum of the reconstructed string
5. Compare computed hash with stored hash

Example using command line (Linux/Mac):
  $ echo -n "1673|Corneille Emmantelée, Monedula, Chouca (Crows, Jackdaws)...|56.644.21(15)|http://..." | sha256sum

Example using Python:
  import hashlib
  data = "1673|Corneille Emmantelée, Monedula, Chouca (Crows, Jackdaws)...|56.644.21(15)|http://..."
  computed = hashlib.sha256(data.encode()).hexdigest()
  print(computed)
