TROUBLESHOOTING QUICK FIXES
================================================================================

Problem: Can't open file in Excel
Fix:     Right-click → Open With → Excel
         When prompted, select "UTF-8" encoding

Problem: Text looks garbled (Chinese/Japanese)
Fix:     Ensure your application is set to UTF-8 encoding
         In Excel: Data → Text to Columns → UTF-8

Problem: Data misaligned in spreadsheet
Fix:     Check that delimiter is set to TAB (not comma or space)
         In Excel: File → Open → Options → Delimiter: TAB

Problem: Python import fails with encoding error
Fix:     Use explicit encoding:
         pd.read_csv('file.tsv', sep='\t', encoding='utf-8')

Problem: File hash doesn't match
Fix:     Re-download the file (may be corrupted in transit)
         Verify CHECKSUMS.txt has correct value

Problem: Validation script says "FILE NOT FOUND"
Fix:     Run from same directory as .py script
         Or specify full path: python3 validate... /full/path/file.tsv
