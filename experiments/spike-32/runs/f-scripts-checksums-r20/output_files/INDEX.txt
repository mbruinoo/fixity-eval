HOW TO USE THIS PACKAGE
═══════════════════════════════════════════════════════════════════════════════

Step 1: Setup (1 minute)
──────────────────────────────────────────────────────────────────────────────
$ chmod +x standardize.sh standardize_tsv.py
$ ls -la standardize*  # Verify files are executable


Step 2: Test (5 minutes)
──────────────────────────────────────────────────────────────────────────────
$ ./standardize.sh met_inventory.tsv
$ ls -lh met_inventory_standardized*
$ head met_inventory_standardized.tsv


Step 3: Verify (2 minutes)
──────────────────────────────────────────────────────────────────────────────
$ sha256sum -c met_inventory_standardized_checksums.txt
met_inventory_standardized.tsv: OK
met_inventory.tsv: OK


Step 4: Review (5 minutes)
──────────────────────────────────────────────────────────────────────────────
$ cat met_inventory_standardized_report.txt
$ cat met_inventory_standardized_checksums.txt


Step 5: Use on Your Files (varies)
──────────────────────────────────────────────────────────────────────────────
$ ./standardize.sh your_file.tsv
# Repeat for each file you want to standardize


Total setup & test time: 15 minutes
