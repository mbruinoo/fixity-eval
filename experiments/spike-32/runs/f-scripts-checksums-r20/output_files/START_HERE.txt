COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: Will this modify my original file?
A: No! Original stays unchanged. Standardized version created separately.

Q: What's a checksum for?
A: Proves file integrity. Can verify anytime it hasn't been corrupted.
   Read: CHECKSUMS_REFERENCE.txt for complete explanation

Q: Do I need internet connection?
A: No! Everything runs locally. No cloud, no external tools required.

Q: Can I use this on Windows?
A: Yes! But install Bash first (WSL, Git Bash, or Cygwin).
   On Mac/Linux: Works directly.

Q: How big can the files be?
A: Works on files from 1KB to gigabytes. Slower for huge files.

Q: Do I need to install anything?
A: Maybe Python if not already installed. Everything else included.

Q: Can I integrate this into my pipeline?
A: Yes! See STANDARDIZATION_GUIDE.md "Integration" section.

Q: What if something goes wrong?
A: Check troubleshooting in STANDARDIZATION_GUIDE.md or this file.

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "Permission denied" when running script
─────────────────────────────────────────────────────────────────────────────
Solution: chmod +x standardize.sh


Problem: "Python not found" or "Python 2"
─────────────────────────────────────────────────────────────────────────────
Solution: Install Python 3
  Ubuntu/Debian: apt-get install python3
  Mac: brew install python3
  Check: python3 --version (should show 3.6+)


Problem: Output files not created
─────────────────────────────────────────────────────────────────────────────
Solution: 
  1. Check file permissions: ls -la
  2. Check disk space: df -h
  3. Check error message from script
  4. Try with sample file first


Problem: Checksum verification fails
─────────────────────────────────────────────────────────────────────────────
Solution: Read CHECKSUMS_REFERENCE.txt troubleshooting section


Problem: Strange characters in output
─────────────────────────────────────────────────────────────────────────────
Solution: Input file needs UTF-8 conversion
  $ iconv -f ISO-8859-1 -t UTF-8 input.tsv > input_utf8.tsv


For more help: See STANDARDIZATION_GUIDE.md troubleshooting section
