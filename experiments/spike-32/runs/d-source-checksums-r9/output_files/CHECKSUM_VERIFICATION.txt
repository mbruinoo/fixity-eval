CHECKSUM METHODOLOGY
================================================================================

Algorithm: SHA-256 (Secure Hash Algorithm)
- Produces 64-character hexadecimal string
- Any byte change produces different hash
- Industry standard for file verification
- Non-reversible (one-way function)

Alternative: MD5 (for legacy compatibility)
- Produces 32-character hexadecimal string
- Faster than SHA-256 but less collision-resistant
- Included for reference only
