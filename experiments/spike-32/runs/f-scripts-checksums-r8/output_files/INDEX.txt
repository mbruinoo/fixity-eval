DATA FORMAT REFERENCE
═══════════════════════════════════════════════════════════════════════════════

File Type:       Tab-Separated Values (TSV)
Delimiter:       Tab (\t)
Line Endings:    LF (\n)
Character Set:   UTF-8
Encoding:        UTF-8 (no BOM)

Column 1: Object Date
  • Date or date range of the museum object
  • Examples: "late 19th century", "1673", "ca. 1479–1458 B.C."
  • May be empty for objects with unknown dates

Column 2: Title
  • Title or description of the artwork/object
  • Examples: "Crows, Jackdaws", "Bell rubbing", "Earrings"
  • May be empty for untitled objects

Column 3: Object Number
  • Museum catalog/accession number
  • Examples: "C.I.46.9.189", "56.644.21(15)", "2017.113.379"
  • Unique identifier in the Met's collection

Column 4: Link Resource
  • URL to the object in the Met Museum collection
  • Starts with: http://www.metmuseum.org/art/collection/search/
  • Provides direct access to full object record
