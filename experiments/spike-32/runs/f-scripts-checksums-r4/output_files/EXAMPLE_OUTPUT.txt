EXAMPLE 9: What Each Script Does
================================================================================

1. standardize_met_inventory.py
   Purpose: Main standardization processor
   Input:   Source TSV file
   Output:  Standardized TSV, standardization_report.json
   Time:    < 1 second
   
2. verify_integrity.py
   Purpose: Verify checksums and data integrity
   Checks:  SHA-256 matches, record counts, field structure
   Output:  Console report
   Time:    < 1 second

3. compare_changes.py
   Purpose: Analyze differences between source and output
   Shows:   Field-by-field changes, change types, statistics
   Output:  Console report + comparison_report.json
   Time:    < 1 second

4. run_standardization.sh
   Purpose: Orchestrate entire workflow
   Steps:   Copy source, run Python scripts, generate manifest
   Output:  All standardization files
   Time:    ~2-3 seconds

EXAMPLE 10: Troubleshooting Output
================================================================================

If something goes wrong, here's what you might see:

"File not found" error:
   → Copy scripts to same directory as data files
   → Check file paths in error message

"Encoding error":
   → File might not be UTF-8
   → Use: file -i met_inventory.tsv
   → To check or convert: iconv -f ISO-8859-1 -t UTF-8 input.tsv > output.tsv

"Permission denied" for scripts:
   → Make executable: chmod +x standardize_met_inventory.py
   → Or use: python3 standardize_met_inventory.py

"Checksum mismatch":
   → File may have been modified
   → Re-run: python3 verify_integrity.py
   → Compare new checksum with MANIFEST.txt
