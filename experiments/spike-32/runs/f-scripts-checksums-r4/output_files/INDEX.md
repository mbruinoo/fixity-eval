## 🔐 Checksum & Integrity Files

### Where to Find Checksums

**standardization_report.json** (machine format):
```json
{
  "source_file": {
    "sha256_checksum": "abc123..."
  },
  "output_file": {
    "sha256_checksum": "def456..."
  }
}
```

**MANIFEST.txt** (human format):
```
SHA-256: abc123...  met_inventory_source.tsv
SHA-256: def456...  met_inventory_standardized.tsv
```

**Command line**:
```bash
sha256sum met_inventory_standardized.tsv
```

### Why Both Checksums?
- **Source checksum** proves what you started with
- **Output checksum** lets you verify the file hasn't been corrupted
- Together they create an audit trail

## 🔄 File Format Reference

### TSV Structure (Tab-Separated Values)
```
object_date		title		object_number		link_resource
late 19th century	[Title]		C.I.46.9.189		http://...
```

### JSON Report Structure
```
{
  "timestamp": "2024-...",
  "source_file": { "sha256_checksum": "...", ... },
  "output_file": { "sha256_checksum": "...", ... },
  "processing_summary": { ... },
  "validation_issues": [ ... ]
}
```

### Python Usage
```python
import csv
import json

# Read standardized TSV
with open('met_inventory_standardized.tsv') as f:
    reader = csv.DictReader(f, delimiter='\t')
    for row in reader:
        print(row['object_number'], row['title'])

# Load report
with open('standardization_report.json') as f:
    report = json.load(f)
    print(report['source_file']['sha256_checksum'])
```
