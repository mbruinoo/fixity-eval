## Python Hash Verification Script
```
import hashlib

def compute_file_hash(filepath, algorithm='sha256'):
    """Compute hash of file using specified algorithm"""
    hash_obj = hashlib.new(algorithm)
    with open(filepath, 'rb') as f:
        for chunk in iter(lambda: f.read(4096), b''):
            hash_obj.update(chunk)
    return hash_obj.hexdigest()

# Verify the file
file_path = 'met_inventory_standardized.tsv'
print(f"MD5: {compute_file_hash(file_path, 'md5')}")
print(f"SHA-1: {compute_file_hash(file_path, 'sha1')}")
print(f"SHA-256: {compute_file_hash(file_path, 'sha256')}")
```

## Bash Hash Verification Script
```bash
#!/bin/bash
FILE="met_inventory_standardized.tsv"

if [ -f "$FILE" ]; then
    echo "File: $FILE"
    echo "MD5: $(md5sum $FILE | awk '{print $1}')"
    echo "SHA-1: $(sha1sum $FILE | awk '{print $1}')"
    echo "SHA-256: $(sha256sum $FILE | awk '{print $1}')"
    echo "File size: $(wc -c < $FILE) bytes"
else
    echo "File not found: $FILE"
fi
```

## Common Issues & Solutions

### Issue: Hash mismatch
**Cause**: File was modified, corrupted, or line endings changed
**Solution**: Re-download/re-verify against source file

### Issue: Encoding errors when opening
**Cause**: File being opened in wrong encoding
**Solution**: Ensure UTF-8 encoding selected (no BOM)

### Issue: Extra characters at line endings
**Cause**: Windows (CRLF) vs Unix (LF) line endings
**Solution**: Convert line endings if needed (dos2unix command or text editor)

### Issue: CJK characters showing as boxes
**Cause**: Display font lacks CJK glyphs
**Solution**: Use font with CJK support (Arial Unicode MS, Noto Sans CJK, etc.)
