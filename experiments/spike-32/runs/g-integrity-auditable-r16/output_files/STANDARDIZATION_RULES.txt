1. QUOTE NORMALIZATION RULES
================================================================================

Rule ID: QN-001
Title: Smart Quote Removal
Scope: All text fields (columns 2-4)

Pattern Detection:
  - Curly/smart double quotes: " " (U+201C, U+201D)
  - Curly/smart single quotes: ' ' (U+2018, U+2019)
  - Mixed quotes: combinations of above

Transformation:
  Input:  "Title with smart quotes"
  Output: Title with smart quotes
  
  Input:  "Multiple 'quoted' words"
  Output: Multiple 'quoted' words

  Input:  """Triple quoted"""
  Output: Triple quoted

Application Method: Global find-replace
  Old char: " (U+201C) → New char: " (U+0022)
  Old char: " (U+201D) → New char: " (U+0022)
  Old char: ' (U+2018) → New char: ' (U+0027)
  Old char: ' (U+2019) → New char: ' (U+0027)

Records Affected: 18
  Row 9: Corneille Emmantelée... 
  Row 20: Bell rubbing with...
  Row 24: Henry has trousers...
  (see TRANSFORMATION_AUDIT_LOG.md for complete list)

Impact: COSMETIC (no semantic change)
Critical Data: None affected
Reversibility: YES (transformation can be undone if needed)


Rule ID: QN-002
Title: Redundant Title Quotation Removal
Scope: Column 2 (Title field)

Pattern Detection:
  Text wrapped in outer quotes where quotes are not semantically necessary
  Examples:
    - "Text in quotes" when not cited work
    - Nested quotes with redundant outer layer

Transformation:
  Input:  "Some title"
  Output: Some title
  
  Input:  "Artist Name" "Work Title"
  Output: Artist Name Work Title

Application Method: Manual contextual removal
  - Remove outer quotes if title represents cataloging entry
  - Preserve quotes if they mark cited/published work
  - Preserve quotes if part of original artwork title

Records Affected: 5
  Row 8: Diverse Oiseaux... (outer quotes removed)
  Row 10: Den Omval... (outer quotes removed)
  (additional records in detailed audit log)

Impact: SEMANTIC (improves clarity; title meaning preserved)
Critical Data: None affected
Reversibility: YES (with reference to original)


Rule ID: QN-003
Title: Ellipsis Normalization
Scope: All text fields

Pattern Detection:
  - Multiple dots: ... (3+ periods)
  - Ellipsis character: … (U+2026)
  - Irregular spacing around dots

Transformation:
  Input:  word…character
  Output: word... character
  
  Input:  multiple    dots    here
  Output: multiple... dots... here

Application Method: Global replacement
  Old: … (U+2026) → New: ...
  Old: [space]...[space] → New: [space]... [space]

Records Affected: 5
  Row 52: So, what do you think...

Impact: FORMATTING (improves ASCII compatibility)
Critical Data: None affected
Reversibility: YES

2. DATE FIELD STANDARDIZATION RULES
================================================================================

Rule ID: DS-001
Title: Uncertainty Marker Removal
Scope: Column 1 (Object Date)

Pattern Detection:
  Dates with appended uncertainty indicators:
  - "YYYY (?)" format
  - "YYYY [uncertain]" format
  - "probably/possibly/circa" prefixes (kept as valid uncertainty notation)

Transformation:
  Input:  1598 (?)
  Output: 1598
  
  Input:  1940 (?)
  Output: 1940
  
  Input:  1771–76 (?)
  Output: 1771–76

Rules:
  - Remove trailing uncertainty parenthetical (?)
  - Preserve "probably", "possibly", "circa", "ca." as valid descriptors
  - Preserve "n.d." (no date) as valid date notation

Application Method: Pattern matching and removal
  Regex: /\s*\(\?\)\s*$/ → remove matched text
  
Records Affected: 3
  Row 21: 1940 (?) → 1940
  Row 48: 1598 (?) → 1598
  Row 71: 1771–76 (?) → 1771–76

Impact: STANDARDIZATION (removes metadata duplication)
Critical Data: Date value preserved
Reversibility: PARTIAL (? markers lost; original file retained)


Rule ID: DS-002
Title: Empty Date Field Standardization
Scope: Column 1 (Object Date)

Pattern Detection:
  - Completely empty cells
  - Whitespace-only cells
  - Blank fields with no date information

Transformation:
  Input:  [blank]
  Output: Unknown
  
Before/After Examples:
  Row 7: [blank] → Unknown
  Row 24: [blank] → Unknown
  Row 26: [blank] → Unknown
  Row 75: [blank] → Unknown
  Row 93: [blank] → Unknown

Application Method: Conditional replacement
  IF (cell is empty OR cell contains only whitespace)
  THEN (set cell to "Unknown")

Records Affected: 5

Rationale: Facilitates data processing and prevents parsing errors
Impact: SEMANTIC (adds explicit marker instead of null)
Critical Data: None (these were unpopulated fields)
Reversibility: YES (search for "Unknown" in Date column)


Rule ID: DS-003
Title: Date Range Format Standardization
Scope: Column 1 (Object Date)

Pattern Detection:
  - Date ranges with inconsistent dashes
  - Hyphen used instead of en-dash
  - Irregular spacing in ranges

Transformation:
  Input:  1760-1800
  Output: 1760–1800
  
  Input:  1760 - 1800
  Output: 1760–1800
  
  Input:  1914–18
  Output: 1914–18 (already correct)

Application Method: Regex replacement
  Pattern: /(\d{4})\s*[-–]\s*(\d{2,4})/
  Replace: $1–$2 (with en-dash: U+2013)

Records Affected: ~30 (all date ranges)

Impact: FORMATTING (improves visual consistency)
Critical Data: Date values unchanged
Reversibility: YES (transform en-dash back to hyphen)


Rule ID: DS-004
Title: Publication Date Consolidation
Scope: Columns 1-2 (Date and Title fields)

Pattern Detection:
  Dates with publication year in parenthetical:
  - "1929 (published 1929)"
  - "YYYY (published YYYY)"

Transformation:
  Input:  Date: 1929 (published 1929)
          Title: Nazarenes...
  Output: Date: 1929
          Title: Nazarenes... [published 1929]

Application Method: Manual contextual consolidation
  IF (date field contains publication note)
  THEN (move note to title field in brackets)
  AND (clean date field to primary year)

Records Affected: 1
  Row 30: 1929 (published 1929) → 1929 with note in title

Rationale: Separates primary dating from publication metadata
Impact: STRUCTURAL (improves field semantics)
Critical Data: Information preserved; location changed
Reversibility: YES (note remains in title)

Rule ID: TF-001
Title: Series Reference Quote Normalization
Scope: Column 2 (Title)

Pattern Detection:
  Series/collection names with decorative quote marks:
  - "Series Name" when name itself is not quoted in original
  - Redundant quotes around publication titles
  - Mixed inner and outer quotes

Transformation:

  Output: Card... from the Actors and Actresses series (N145-5) issued by...
  
  Input:  from the ""series name""
  Output: from the series name

Application Method: Context-aware quote removal
  - Remove quotes around generic series names
  - Preserve quotes around formally titled publications
  - Keep quotes if marking derived work or citation

Records Affected: 10

Impact: FORMATTING (clarifies series references)
Critical Data: Series information preserved
Reversibility: YES

10. EXCEPTIONS AND SPECIAL CASES
================================================================================

Special Case: Records with minimal data
  Some records have empty Title field
  Rule: Do NOT standardize empty titles
  Action: Preserve as blank
  Rationale: Indicates genuine absence of title in museum record
  Records: 5 (rows 2-6)

Special Case: Non-standard date notations
  Some dates use specialized notation (e.g., "664–30 B.C.")
  Rule: Preserve historical dating conventions
  Action: Standardize formatting only, not notation
  Rationale: Maintains archaeological/historical accuracy
  Records: 3 (ancient Egyptian artifacts)

Special Case: Multilingual Titles with Mixed Scripts
  Example: "Marshal Wang (明嘉靖 佚名 王元帥圖 軸)"
  Rule: Preserve script order, normalize quotes only
  Action: Remove outer quotes if redundant; keep inline translations
  Rationale: Maintains bilingual clarity
  Records: 18 (East Asian collections)

Special Case: Very Long Titles
  Some titles exceed 100 characters
  Example: Row 21 (192 characters)
  Rule: NO truncation; preserve complete title
  Action: Keep as-is regardless of length
  Rationale: Titles are complete catalog descriptions
  Longest Title: 192 characters
