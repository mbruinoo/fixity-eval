KEY CONCEPTS
================================================================================

Standardization:
  Process of normalizing file format (encoding, line endings, spacing)
  to ensure consistency and compatibility.

Checksum (Digest):
  A unique digital "fingerprint" computed from file contents.
  Used to detect corruption or changes.
  Two types used: MD5 (legacy) and SHA256 (secure).

Manifest:
  Machine-readable metadata file (JSON) containing:
  - Checksums of source and output files
  - File sizes and timestamps
  - Statistics (rows, columns)
  - Issues identified
  - Standardization rules applied

Audit Log:
  Human-readable record of processing showing:
  - When processing occurred
  - What was done
  - Results and statistics
  - Any issues found

Integrity Verification:
  Process of checking checksums to confirm file hasn't been:
  - Corrupted during storage
  - Corrupted during transfer
  - Tampered with
  - Modified by accident
