    for i, line in enumerate(lines[1:], 1):

      if len(parts) >= 6:

Q: Is all my original data preserved?
A: Yes. 100% of original content is intact. We only added 2 columns
   (Row_ID and Data_Hash) and standardized column names.

Q: Can I modify the data?
A: Yes. If you modify records, recompute Data_Hash using the formula:
   MD5(Object_Date | Title | Object_Number | Link_Resource)

Q: What if verification fails?
A: See VERIFICATION_GUIDE.md Section 6. Common issues:
   • Wrong encoding (use UTF-8)
   • File corruption (re-download)
   • Line ending mismatch (normalize to LF)

Q: How do I handle the multilingual content?
A: The data is stored in UTF-8. Your system must support UTF-8 to display
   correctly. All data is intact regardless of display issues.

Q: Can I use this data commercially?
A: Yes. The Met Museum Collection is public domain. Attribution appreciated.

Q: What about future updates?

   https://metmuseum.github.io/

Q: How do I know if my database import worked?

Q: What if a record has an empty title?
