**Notes on what changed and what I left alone:**
- "ca." became "c." throughout.
- Spacing and dash styles were unified (en dashes for ranges, a space before "BCE"/"CE").
- Ranges like "1780–81" were expanded to "1780–1781" for consistency.
- "B.C." became "BCE" where it appeared.
- Entries that are inherently vague ("18th century", "unknown", "n.d.") were kept as-is, since converting them to a single year would invent precision that isn't in the source.
- Entries with a blank date were left blank.
- I didn't alter the non-date columns beyond what was necessary to keep the file intact. Note that a few entries contain commas inside values, so they're quoted where needed.

If you want a single machine-readable format instead (e.g., start year and end year as separate columns), I can restructure it that way.
